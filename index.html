Reference stack

Python 3.14 · FastAPI · Pydantic · SQLAlchemy 2 · Alembic · NATS JetStream · PostgreSQL · ClickHouse · Redis · OpenSearch · Next.js 16 · React · TypeScript · Tailwind · Lightweight Charts.

Smart Search

Query planning → lexical/BM25 + vector → hybrid fusion/RRF → reranking → evidence → synthesis → citation verification. Fusion and reranking parameters are selected only after workload-specific relevance and latency evaluation.

Trading Terminal

Chart-first full-screen UX, realtime market data, FVG, Order Block, MTF, signals, replay, risk sizing, journal, attribution and notifications.

Governed Autonomy

Observe → diagnose → research → propose → sandbox → test → canary → health gate → promotion/rollback. High-impact actions remain policy-controlled.

Release definition

هیچ release فقط با تست feature خودش معتبر نیست. کل repository باید از نظر imports/runtime، فایل‌های خالی یا operationally-empty، security، performance، data integrity، contracts، frontend، search quality، AI evaluation، observability، migration و rollback بررسی شود.

مسیر مطالعه

  2. Graph برای وابستگی و جریان end-to-end.
  3. Contracts برای API/event/domain interfaces.
  4. Domains و Projects برای ownership.
  5. Research و AI/Elyrava برای intelligence.
  6. Trading و Frontend برای terminal.
  7. Security، Observability و Testing برای production readiness.
  8. Governance، Autonomy و ADRs برای کنترل تغییر.
