Roadmap

  1. Foundation: contracts، schemas، source registry و canonical document.
  2. Ingestion: crawler/connectors، parser، dedupe، chunking و freshness.
  3. Indexing: lexical + vector indexes و metadata filtering.
  4. Retrieval: hybrid fusion، routing و reranking.
  5. Intelligence: evidence، synthesis، citations و confidence.
  6. Evaluation: golden set، offline benchmark و regression gates.
  7. Production hardening: security، rate limits، caching، multi-tenancy و cost controls.

Definition of Done

  • پاسخ factual مهم بدون provenance تولید نشود.
  • providerها پشت interface باشند.
  • retrieval و generation جدا benchmark شوند.
  • تغییر ranking/model regression test داشته باشد.
  • fetch خارجی SSRF و redirect abuse را کنترل کند.
  • latency تمام stageها قابل مشاهده باشد.
