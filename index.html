Non-negotiable rules

1. CForex is behavioral source evidence; CFIP is the destination.
2. cforex-platform is permanently excluded unless explicitly reversed.
3. CFIP owns domain contracts, policy, invariants and orchestration.
4. Mature OSS capabilities are integrated/adapted behind replaceable boundaries.
5. No blind code copying; inspect license, maintenance, tests, security and runtime fit.
6. Raw external evidence is provenance-aware and untrusted.
7. AI output cannot bypass risk/execution policy.
8. Every autonomous proposal needs sandbox evidence, tests, approval and rollback.
9. Whole-repository release audits are mandatory.
10. Completion means every capability has an owner, contract, data boundary, security class, observability plan and verification gate.
