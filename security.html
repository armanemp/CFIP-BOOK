Security Architecture

Defense in depth

Security is enforced at identity, network, application, data, AI-tool and supply-chain boundaries. Administrative paths are governed and auditable.

Identity

OAuth/OIDC, secure sessions, MFA-ready design, tenant context and least privilege.

Application

Input validation, authorization at resource boundaries, CSRF where applicable, rate limits, SSRF controls and safe error handling.

Secrets

No secrets in source, images, logs or client bundles. Rotation and environment injection are explicit.

AI security

Tool allowlists, sandboxing, prompt-injection resistance, untrusted-content isolation, egress controls and approval gates.

Supply chain

Pinned/controlled dependencies, vulnerability review, lockfiles, provenance, reproducible builds and artifact verification.

Admin Git boundary

Administrative repository operations use an explicit governed boundary with authorization, allowlists, audit and protected destructive operations.

Security release gate

Threat model updated • dependency audit • secret scan • authz tests • abuse cases • SSRF/injection tests • audit verification • rollback exercise.
