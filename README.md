# CFIP Book

## Smart Search Intelligence — Matrix & Graph

این مخزن محل نگهداری مستندات، ماتریس فناوری و گراف معماری **Smart Search Intelligence** برای CFIP است.

### محتوای فعلی
- `index.html` — نسخه مستقل و بدون dependency خارجی از ماتریس و گراف
- `data/technology-matrix.json` — داده ساختاریافته فناوری‌ها
- `docs/SMART-SEARCH-INTELLIGENCE.md` — راهنمای معماری و ارزیابی

این پروژه باید به‌صورت تدریجی و استاندارد تکمیل شود و هر نسخه قابل اجرا و قابل بررسی باقی بماند.
