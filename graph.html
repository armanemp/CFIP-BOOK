System Graph

End-to-end intelligence flow

The graph is intentionally layered: experience, policy, orchestration, retrieval, evidence, intelligence, data, events and operations. Dependencies should point inward through stable contracts.

User / Terminal→Identity + Policy→Query Planner→Lexical+Vector→Fusion / RRF→Reranker→Evidence Store→Elyrava→Citations + Answer

Data plane

Market, web, GitHub and user data are ingested with provenance, content hashes, timestamps, schema versions and quality signals.

Control plane

Identity, policy, feature flags, configuration, entitlements, approvals and audit records control behavior without hardcoded user-facing settings.

Learning plane

Datasets → evaluation → sandbox → candidate → canary → health gate → promotion or rollback.

Failure plane

Timeouts, retries, circuit breakers, idempotency, dead-letter streams, replay and graceful degradation are explicit architectural paths.
