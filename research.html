Research Intelligence Fabric

Search, verify, cite, learn

Research is treated as a reproducible data pipeline: discover → fetch → parse → normalize → deduplicate → rank → verify → cite → store provenance → build dataset.

Discovery

Query decomposition, source diversity, domain constraints, search result harvesting and query expansion.

Acquisition

HTTP retrieval, robots-aware crawling, browser rendering when required, retries, timeouts and content hashing.

Parsing

HTML/PDF/document extraction, structural segmentation, metadata capture and parser confidence.

Evidence

Every claim maps to source, location, retrieval time, content hash and transformation lineage.

Freshness

Time-sensitive domains use freshness budgets and revalidation gates before evidence is eligible for current claims.

Evaluation

Recall@k, MRR, nDCG@k, citation coverage, source quality, freshness, contradiction rate and abstention quality.

Smart-search reference pipeline

Query → Planner → Lexical/BM25 + Vector → Fusion/RRF → Reranker → Evidence → Synthesis → Citation verifier → Answer
