Frontend & Terminal UX

Chart-first, realtime, accessible

Next.js 16 + React + TypeScript + Tailwind form the shell. TradingView Lightweight Charts is the visualization foundation. The product is a terminal, not a collection of dashboard pages.

Layout

Full-screen chart canvas with side rail, bottom bar, drawers, popovers and modals. Avoid unnecessary page scrolling.

Realtime

WebSocket/SSE subscriptions with reconnect, backoff, sequence handling, stale-state indicators and bounded client buffers.

Accessibility

Keyboard navigation, focus management, semantic controls, reduced-motion support, contrast and screen-reader labels.

i18n

Translation keys, locale-aware formatting, RTL/LTR layouts, timezone/currency conventions and no user-facing hardcoded strings.

Performance

Code splitting, lazy tools, chart rendering budgets, minimized re-renders, cache-aware data fetching and mobile constraints.

SEO/PWA

Metadata, canonical URLs, structured navigation, manifest, service worker strategy and resilient offline shell where appropriate.
