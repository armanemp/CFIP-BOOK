Autonomy

Self-improvement with hard boundaries

Autonomy is graduated. The system may observe, diagnose, research, propose, implement in a sandbox, test and produce evidence; production promotion and high-impact actions remain policy-gated.

Observe

Telemetry, quality metrics, failures, drift, user feedback and release history.

Diagnose

Cluster failures, identify likely causes, reproduce with fixtures and distinguish symptoms from root causes.

Research

Use web/GitHub/source corpora with freshness and provenance requirements.

Propose

Create a bounded proposal with expected benefit, risk, files/components, tests, rollback and evidence requirements.

Sandbox

Write code in isolated workspaces, run tests, static checks and benchmark experiments without production mutation.

Promote

Candidate → CI → security → quality → canary → health guard → approval/policy → promotion or rollback.

Autonomy levels

L0 ObserveL1 RecommendL2 SandboxL3 Low-risk auto-promotionL4 Governed production action

Level is assigned per action class, not globally to the AI.
