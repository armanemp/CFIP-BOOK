CFIP Ecosystem Book
Deployment

Reproducible runtime topology

Development, staging and production use the same architectural contracts. Environment-specific values are injected through configuration and secrets, never embedded in code.

Edge

TLS termination, WAF/rate limiting, CDN/static assets and request correlation.

Application

FastAPI services, workers and scheduled jobs. Stateless where possible; durable state belongs in explicit stores.

Events

NATS JetStream cluster with durable consumers, replay policy, DLQ and operational dashboards.

State

PostgreSQL for transactional state; ClickHouse for analytical workloads; Redis for cache/ephemeral coordination; object storage for immutable artifacts.

Search

OpenSearch cluster with lexical, vector and hybrid pipelines plus measured reranking.

Operations

OpenTelemetry collection, alerting, SLOs, backups, restore tests, deployment health checks and rollback.

Resource-aware development

Local development must remain viable on constrained hardware: service profiles, bounded concurrency, small datasets, optional heavyweight services and reproducible offline fixtures.
